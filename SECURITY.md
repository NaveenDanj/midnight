# Security Policy

## Supported Versions

Midnight is currently under active development. Security updates are provided for the latest development branch only.

| Version | Supported |
| ------- | --------- |
| main branch | :white_check_mark: |
| Older commits/releases | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in Midnight, please report it responsibly.

Do not open a public GitHub issue for security-related problems. Public disclosure may put users and contributors at risk before a fix is available.

Instead, report vulnerabilities through:

- GitHub Security Advisories:  
  https://github.com/naveendanj/midnight/security/advisories/new

Please include as much information as possible:

- A description of the vulnerability
- Steps to reproduce the issue
- Affected components (compiler, runtime, standard library, tooling, etc.)
- Potential impact
- Any suggested fixes or mitigations

## Response Process

After receiving a vulnerability report:

1. We will acknowledge the report as soon as possible.
2. The issue will be investigated and validated.
3. If confirmed, a fix will be developed and tested.
4. A security advisory may be published after a fix is available.

We appreciate responsible disclosure and the efforts of security researchers and contributors who help improve Midnight.
